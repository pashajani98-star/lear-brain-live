⚿ CONTROL LINK AUTHORIZATION

To control agents from this dashboard, it needs a GitHub token to write commands into the repo. The brain laptop picks them up and executes them.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: only lear-brain-live
  3. Permissions: Contents → Read and write
  4. Paste the token below. It is stored only in this browser.
